# DeltaNetcode

DeltaNetcode is intended to provide engine-independent, high-performance networking for .NET applications.

## Project status

This repository currently contains the project scaffold only. It does not yet provide a public API, a transport, or a published package.

## Target frameworks

The primary project targets .NET Standard 2.1 and .NET 10. The first target keeps the core usable from a broad range of .NET runtimes; the modern target allows implementations to use current runtime capabilities where needed.
